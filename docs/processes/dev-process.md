# Développement

Le workflow Roxabi démarre avec `/R-dev #N` une fois l'issue définie. Le socle n'a créé ni issue ni GitHub Project.

Pour une modification courte, implémenter puis contrôler et relire. Pour une nouvelle capacité, cadrer le problème, définir les critères d'acceptation, préparer un plan et documenter les décisions avant intégration.

Les artefacts suivent les chemins `.dev/stack.yml`. Les répertoires sont créés avec leur premier artefact, sans fichiers de remplissage.
